从流中读取 JSON 值对象

这个函数会尝试解析 JSON 格式的字符串，并将解析结果存储在当前 JSON 值对象中 它会忽略冗余的空白符、注释和尾随逗号

注解
若在读取时遇到错误，会设置流状态为 failbit
